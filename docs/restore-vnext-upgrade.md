# Restore vNext — 首批架构改造

状态：首批代码已在 PR #8 接入主流程，待合并；这份文件记录落地边界，不把设计提案当成运行成果。唯一 SOP、接口、Loop Criteria 和最终评测仍沿用原控制文件。大版本采用向后兼容的增量，先打通证据→规格→实施→校验→回放，再按真实缺口增加工具。

本版现按四个优化项组织：还原准备与资产规范、视觉交互与音频、持久迭代闭环、轨迹可观测与过程评估。下表记录首批网站侧增量；后续轨迹/评估模块、依赖、接口复用及未激活能力统一见[整体架构](architecture.md)，工程验证入口见[检查流程](../evals/README.md#统一工程检查)。

| 优化项 | 本版落地 | 仍需验证/后续 |
| --- | --- | --- |
| U01 任务模式/标准 | 沿用四种工作流、Loop 与 E2E 分离 | 不新增混合总分 |
| U02 三层取证 | 沿用源码、视觉、手势采集；准备规格引用证据 | 没有自动穷尽全站扫描器 |
| U03 资产/状态完备性 | 必需覆盖、未知与所用缓存哈希门禁 | 完备性分母仍依赖正确 scoping |
| U04 证据冻结 | 合同整体哈希；旧记录不迁移 | 新任务漏项必须 refreeze |
| U05 设计 DNA | token 与逐状态 region 数据 | 提取仍由 Agent 完成 |
| U06 分块 plan | 有依赖、优先级和验收引用的任务；brief 投影 | 未做自动任务调度平台 |
| U07 几何细节 | 绑定捕获的诊断套件；缺失/隐形不能通过 | Canvas 内部 bbox 不自动识别 |
| U08 视觉表示 | representation 路由声明和素材指南 | 没有新增 3D/图像/视频服务 |
| U09 动效 | 有限表达式、转换、track、坐标与帧证据 | 不执行通用 DSL 或自动拟合物理 |
| U10 游戏逻辑 | 区分逻辑态与 capture state；保留真实路径检查 | 不新建游戏/叙事引擎 |
| U11 BGM/SFX | cue、素材引用、audio 证据和报告播放 | 生成工具连接与听感校准待真实需求 |
| U12 准备门禁 | init-vnext、prepare-check、freeze fail-closed | limited 不代表完整验收 |
| U13 高影响修复 | 计划优先级 + 既有有界单问题 Loop | 无自动收益预测 |
| U14 工具路由 | 按缺口和宿主能力选择 | 不自动安装/宣称工具可用 |
| U15 目录 | 默认分类、可扩展 profile、现有布局映射 | 不自动迁移文件或改 loader |
| U16 实路回归 | 沿用隔离时钟、手势和同语义轨迹 | Firewood 只做限定诊断范围 |
| U17 匿名比较 | inline 媒体、私有映射、双向调用、请求 ID 绑定 | 裁判校准与全局优效尚未证明 |
| U18 音频验收 | 正式音频证据类型、可播放报告 | 调用日志不等于听感验证 |
| U19 最终 E2E | 原五维与红线不变 | 不用局部偏好填造最终分 |
| U20 Schema/所有权 | optimization v1、generation v2、严格投影 | 保留个人离线 Skill 定位 |
| U21 继承 | continue/refreeze 复制哈希验证的规格资产缓存 | 不改写父账本 |
| U22 恢复/进度 | 任务级持久游标、会话绑定、累计预算、分阶段恢复、幂等子 run 交接；项目生命周期 hook | 适配器可测；宿主信任与回调→续跑→进展仍须实测；不增加常驻服务 |
| U23 报告/回放 | 优化规格投影、原始轨迹与 audio 播放 | 新页仍需桌面/窄屏实测 |
| U24 离线迭代 | RED→GREEN 回归、Firewood 原始失败记录、证据绑定的 Skill 改进提案 | 不自动修改 Skill，不接入留出反馈，不把单案例当泛化或训练效果 |
| U25 兼容迁移 | 基线 checkpoint、独立分支与验收协议 | 未合并、未发布；效果待配对实验 |

本次经典问题是“带证据的规格驱动重建”和“有混杂因素的配对评估”：记录变多只提高可检查性，不能自行证明还原质量。验收方法与对比资格由 [vnext-acceptance](../evals/vnext-acceptance.md)控制。

优先路线：先完成本版代码/契约/浏览器回归与 Firewood 诊断；再用同冻结任务、同预算和同工具运行旧/新完整尝试；最后按内容站、强动效、Canvas/3D、玩法和音频需求分层复验。总耗时须包含 inspect/spec 开销；缺少历史成本或独立质量时不输出提效百分比。
