# 取证方法

## 环境与行为

记录来源 URL/文件、采集日期、浏览器及版本、视口、DPR、缩放、滚动位置、输入方式、网络/设备条件和 reduced-motion 设置；对视频记录原始时长、帧率或变帧、裁切/倍速及起始时间。保护会话信息，不输出 cookie、令牌或私人数据。按风险和授权范围执行操作：优先无副作用地 hover、focus、滚动和展开；提交、购买、删除等有外部影响的操作不得为了探测而擅自执行。

为每个动作记录前置条件、起始状态、动作及参数、结果、重置路径和时间线。覆盖初次加载、重入、hover/离开、focus/blur、按下/释放、键盘、点击、滚动上下往返、resize、等待、播放/暂停及适用的失败/中断/重复路径。滚动记录触发位置、元素相对视口位置和方向；区分时间驱动与滚动进度驱动。记录未访问状态及原因，避免穷举不可能的全部状态。

## 状态决策与采集时机

- **尚未触发**：从主要路径与可见线索建立优先队列，记录前置状态，按队列执行操作。某个入口不可达或受限时记录原因并继续其他可访问路径；不要把没有触发视为没有动画。
- **正在发生**：在采集能力允许时同步记录动画对象、目标属性和连续画面，保存与操作对齐的时间戳。一次快照不足时重复采样或录屏；捕获到的内容仍受采样频率和工具覆盖限制。
- **已经结束且可重现**：通过真实复位路径恢复条件，先布设记录再刷新或触发；同时对照正常运行，标记慢放、暂停或注入等干预。不要使用未授权的存储预置来伪造路径。
- **已经结束且不可重现**：检查已有录屏、日志和允许访问的规则；若没有足够证据，列出 unknown 及补证方式，不能从终态重建唯一轨迹。
- **视频或静态图**：视频按实际时间戳分析，不假设知道触发原因；单张图只记录可见状态。不可访问来源时报告阻塞，不编造条目。

需要在页面自身脚本启动前布设观察时，若浏览器支持，可使用预加载脚本；这并不保证捕获全部机制。CSS 动画和 transition 可监听启动、结束、取消事件并同步保存采样；事件并不覆盖所有动画类型，且取消可能没有正常结束事件。采集代码或降低播放速度可能改变行为，应保留无干预基线并在证据中标注。

## L1 声明式运行时

在页面加载后及关键触发发生时分别检查 `document.getAnimations()`；在短动画期间尽早采样并考虑 shadow root、同源 iframe 和伪元素的可访问性。对可用的 effect 读取 `getKeyframes()`、`getTiming()` 和 `getComputedTiming()`，并记录目标、动画类型、播放状态、采样时刻、播放速率、时间线及动态 computed style。检查可访问样式规则中的 transition、animation、keyframes、媒体条件和伪类；记录规则不可读及异常，跨域 `cssRules` 可能抛出 SecurityError。规则值与当时渲染结果不同要同时记录。`getAnimations()` 是时刻快照，不是全部交互或所有动画的清单；空结果不表示无动效，JS、Canvas/WebGL 等未必出现在这里。

## L2 库驱动

仅在可访问且获准的前提下检查对象、文档化 API 和页面可观察表现。GSAP 暴露时可读取 `gsap.globalTimeline` 的子项与时间信息，`ScrollTrigger.getAll()` 可列出当前实例；它们可能不在全局、尚未创建或已经移除。Framer Motion、Lottie、Lenis、IntersectionObserver 等不能统一假设存在全局对象或可枚举完整状态：仅记录确实获得的实例/配置；否则由行为和视觉补充。只读检查优先，避免暂停、改变时间线或注入会改变正常行为的钩子；确需改变时明确标记采样条件并还原，不能把干预结果当正常播放证据。

## L3 行为探测

用浏览器实际输入，按动作前、动作中多时刻、完成后采集可访问 DOM、边界框与相关 computed styles；识别节点增删、class/属性和 opacity、transform、尺寸、颜色、滤镜等变化。diff 只表示采样差异，不自动证明因果；复测同一动作及反向路径。必要时捕获网络/应用状态变化，但不泄露敏感数据。动画瞬间快照可能漏掉关键阶段，应采样或录制完整过程；对动态数据与异步加载影响做注记。

## L4 视觉与视频

保留原视频或录屏，确定时间基准，按 fps 或实际时间戳抽取关键帧；覆盖起始、触发、过渡、峰值/转折、结束、反向及中断，短动画适当密集采样。必要时生成带时间戳的接触表、差分图和目标中心/边界框随时间曲线；先对齐视口、裁切、缩放及滚动，再判断运动而非把相机/页面移动当物体运动。用可辨识锚点、坐标系和单位给出位移、速度趋势、缩放、旋转、透明度和层级变化；标明遮挡、动态背景和压缩等误差来源。恒定帧率视频的单事件时间精度至少受帧间隔限制；可变帧率应依据实际时间戳。少数帧通常不能唯一确定 easing 或弹簧参数，标 `unknown`，可给候选范围及复核办法。截图本身只能支持单状态，不能推断完整动画。
